# Функциональность удаления чатов

## Обзор

Добавлена возможность удаления истории чатов - как отдельных чатов, так и всей истории целиком.

## Новые возможности

### ✅ Удаление отдельных чатов
- Удаление конкретного чата по ID
- Защита активного чата от удаления
- Проверка принадлежности чата пользователю

### ✅ Удаление всей истории
- Удаление всех неактивных чатов
- Очистка активного чата (сохранение структуры)
- Подсчет количества удаленных чатов

## Эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| `DELETE` | `/cardio-assistant/history/{chat_id}` | Удалить конкретный чат |
| `DELETE` | `/cardio-assistant/history` | Удалить всю историю |

## Безопасность

- ✅ Авторизация обязательна
- ✅ Пользователь может удалять только свои чаты
- ✅ Активный чат защищен от удаления
- ✅ Валидация входных данных

## Примеры ответов

### Успешное удаление чата:
```json
{
  "message": "Чат успешно удален"
}
```

### Успешное удаление всей истории:
```json
{
  "message": "Вся история чатов успешно удалена",
  "deleted_count": 3
}
```

### Ошибка - активный чат:
```json
{
  "detail": "Cannot delete active chat. Please activate another chat first."
}
```

## Использование

### JavaScript (фронтенд):
```javascript
// Удаление конкретного чата
await fetch(`/cardio-assistant/history/${chatId}`, {
  method: 'DELETE',
  headers: { 'Authorization': `Bearer ${token}` }
});

// Удаление всей истории
await fetch('/cardio-assistant/history', {
  method: 'DELETE', 
  headers: { 'Authorization': `Bearer ${token}` }
});
```

### cURL:
```bash
# Удалить конкретный чат
curl -X DELETE "http://localhost:8000/cardio-assistant/history/123" \
  -H "Authorization: Bearer your_token"

# Удалить всю историю
curl -X DELETE "http://localhost:8000/cardio-assistant/history" \
  -H "Authorization: Bearer your_token"
```
