# Улучшение контекстной фильтрации медицинских вопросов

## Проблема

Ранее система фильтрации медицинских вопросов работала только с последним сообщением пользователя, не учитывая контекст всей беседы. Это приводило к тому, что уточняющие вопросы типа "объясни подробнее" или "как улучшить" блокировались системой, даже если они были продолжением медицинской беседы.

## Решение

Реализована умная контекстная фильтрация, которая:

1. **Анализирует контекст всей беседы** - проверяет наличие медицинских ключевых слов в предыдущих сообщениях
2. **Различает типы вопросов** - первичные медицинские вопросы vs. уточняющие вопросы
3. **Использует пороговую логику** - если 30% или больше сообщений содержат медицинские термины, беседа считается медицинской

    if len(messages) == 1:

## Ключевые особенности

### Расширенный список медицинских ключевых слов

Включает термины на русском и английском языках:
- Анатомия: сердце, сосуды, артерии, вены
- Симптомы: боль, давление, пульс, аритмия
- Диагностика: экг, узи, анализ, результат
- Лечение: лекарство, таблетка, врач, кардиолог
- Образ жизни: диета, спорт, курение, стресс

### Умная логика контекста

- **Порог 30%** - если треть или больше сообщений содержат медицинские термины, беседа считается медицинской
- **Анализ последних 10 сообщений** - для построения промпта ИИ
- **Логирование** - подробная информация о процессе фильтрации

### Улучшенные инструкции для ИИ

ИИ теперь получает четкие указания:
- Отвечать на медицинские вопросы
- Продолжать медицинские беседы
- Отвечать на уточняющие вопросы в медицинском контексте
- Не отвечать на полностью не связанные темы

## Примеры работы

### Сценарий 1: Успешное продолжение медицинской беседы

```
Пользователь: "У меня болит сердце, что делать?"
ИИ: "Вам нужно обратиться к кардиологу..."
Пользователь: "Объясните подробнее"
ИИ: "Продолжает давать медицинские рекомендации" ✅
```

### Сценарий 2: Блокировка не-медицинского вопроса

```
Пользователь: "Какая погода сегодня?"

```

### Сценарий 3: Умная фильтрация в смешанной беседе

```
Пользователь: "У меня болит сердце"
ИИ: "Обратитесь к врачу"
Пользователь: "Какая погода?" (блокируется)
Пользователь: "А как лечить?" (разрешается - медицинский контекст)
```
